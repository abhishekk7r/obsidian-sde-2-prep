## JVM — Java Virtual Machine
**JVM** is the engine that runs you java programs.
- It reads the **bytecode** generated by the Java compiler and ==converts it into **machine code**==.
- ==JVM is platform dependent but the bytecode it runs is platform independent.
- JVM includes **JIT compiler (Just-In-Time)** which helps improve performance by compiling code during execution.

## JRE — Java Runtime Environment
**JRE** = _JVM + Class Libraries_
- If you just want to run your program, JRE is enough.
- It includes **JVM + Class Libraries**
