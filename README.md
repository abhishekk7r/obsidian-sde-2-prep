# SDE-2 Prep

Personal Obsidian vault for SDE-2 interview preparation. Open **[[00 Index]]** to navigate.

## Structure
- `01 Companies/` — one note per company: questions asked, how I tackled them, outcome
- `02 Java/` — fundamentals, HashMap, collections, modern Java
- `03 Concurrency/` — threads, locks, atomics, coordination, deadlock, executors
- `04 Spring Boot/` — IoC/DI, auto-configuration, REST, transactions
- `05 Data & Messaging/` — indexing, SQL
- `06 AWS/` — Lambda, SQS/DLQ, DynamoDB, CDK, Bedrock
- `07 System Design/` — concepts, HLD, LLD, design patterns
- `08 Behavioral & Projects/` — story bank, region migration, production debugging
- `Excalidraw/` — drawings

DSA notes live in the "Revision Questions" Google Sheet, not here.

## GitHub formatting
Written for **Obsidian**: callouts, wikilinks and embedded diagrams don't render on GitHub. Clone the repo and open the folder as a vault in Obsidian.
